Web Technologies

HTML

HTML (HyperText Markup Language) is the standard code used to create and structure web pages on the internet. It uses special labels called tags to organize plain text into readable headings, paragraphs, images, and links. Web browsers read this code to display the final visual layout for users to see

CSS

Cascading Style Sheets (CSS) is a cornerstone stylesheet language used to specify the presentation, layout, and visual styling of documents written in markup languages like HTML and XML. Along with HTML (structure) and JavaScript (behavior), CSS forms the fundamental three core technologies of the World Wide Web

Javascript

JavaScript (JS) is a lightweight, cross-platform, and multi-paradigm programming language that serves as one of the core technologies of the World Wide Web, alongside HTML and CSS. It is primarily known for making web pages dynamic and interactive. However, modern modern environments also run JavaScript outside of browsers—such as on servers, databases, and embedded systems
